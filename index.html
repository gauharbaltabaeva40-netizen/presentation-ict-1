01 — The Big Picture

What is computer architecture?

It is the way computer components are organized and connected so they can process data efficiently.

Input

Keyboard, mouse, camera and sensors send data into the system.

Process

The CPU follows instructions and performs calculations and logical operations.

Output

The computer sends the result to a display, speaker, network or storage device.

04 — CPU vs GPU

Different processors for different jobs.

CPU — Few powerful cores

Best for general tasks, logic, operating systems and low-latency decisions.

GPU — Many smaller cores

Best for parallel work such as graphics, simulations and AI calculations.

09 — Instruction Set

Hardware understands a small set of machine instructions.

An Instruction Set Architecture, or ISA, defines what operations a processor can perform and how software communicates with the CPU.

Store

Simple example

LOAD data → ADD values → STORE the result.

The ISA is the bridge between software instructions and processor hardware.

10 — Cache Memory

Cache keeps important data close to the CPU.

It reduces waiting time by storing frequently used information in very fast memory.

L1

Very small and extremely fast. Usually closest to each processor core.

L2

Larger than L1, but slightly slower. Still much faster than RAM.

L3

Larger shared cache that can be used by several CPU cores.

CPU bottleneck

The processor cannot prepare tasks fast enough.

Memory bottleneck

Storage bottleneck

13 — Why Architecture Matters

Different computers need different design priorities.

Architecture is chosen according to the task: gaming, mobile computing, servers, AI, embedded devices or supercomputers.

✓
Gaming: strong CPU and GPU cooperation.
✓
Phones: high efficiency and low power use.
✓
Servers: reliability, memory and parallel workloads.
✓
AI systems: specialized accelerators for matrix calculations.
